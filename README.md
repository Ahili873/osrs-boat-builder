# OSRS Boat Builder

Plan your Old School RuneScape Sailing boat: pick a raft, skiff or sloop, fit every slot, and see the levels, schematics, crew and materials you need, with GE costs and an ironman gathering list.

**Live site:** https://ahili873.github.io/osrs-boat-builder/

## Found a mistake?

Open an issue in this repo's [Issues](https://github.com/ahili873/osrs-boat-builder/issues) tab with the part, what the tool says, and what's correct in game.
